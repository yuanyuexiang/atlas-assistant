## 💡 前端开发建议

### 1. API 响应格式适配

**列表接口可能返回格式**:
```json
{
  "items": [...],
  "total": 100,
  "skip": 0,
  "limit": 10
}
```

**前端代码建议**:
```typescript
// 适配列表响应
const response = await api.get('/agents');
const agents = response.data.items || response.data || [];
```

### 2. 文件上传修复

**测试显示上传失败，需要确认**:
- 字段名: `file` or `files`?
- 是否需要多文件: `files[]`?
- Content-Type 是否正确

**建议实现**:
```typescript
const formData = new FormData();
formData.append('file', fileObject);  // 单数还是复数？
```

### 3. 对话错误处理

**当前对话返回错误提示，可能原因**:
1. 知识库为空 → 上传文档后测试
2. LLM 配置错误 → 后端检查
3. RAG 检索失败 → 后端日志分析

**前端建议**:
- 显示友好的错误提示
- 引导用户上传知识库
- 提供重试机制

### 4. 健康检查

**建议实现**:
```typescript
// 可能的正确路径
await api.get('/health')  // 当前返回404
await api.get('/')        // 尝试根路径
await api.get('/api/health')  // 尝试带api前缀
```
