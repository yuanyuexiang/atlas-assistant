## ⚠️ 需要修复的问题 (6项)

### 1. 列表接口格式 (4项)
**影响模块**: 智能体列表、客服列表  
**状态**: 返回200但前端解析失败  
**原因**: 可能返回分页对象 `{items: [], total: 0}`

**解决方案**:
```typescript
// 前端适配
const agents = response.data.items || response.data || [];
```

### 2. 文件上传 (1项)
**影响模块**: 知识库上传  
**状态**: 返回400  
**原因**: 字段名或格式不正确

**需要确认**:
- 字段名: `file` 还是 `files`?
- 单文件还是多文件?
- 是否需要其他参数?

### 3. 健康检查 (1项)
**影响模块**: 系统监控  
**状态**: 返回404  
**原因**: 路径不存在或错误

**可能正确路径**:
- `/` 根路径
- `/api/health`
- 或不提供此端点
